# Checklist de entrega

Usar esta lista antes de presentar la web al cliente.

## Web pública

- Revisar home.
- Revisar listado de propiedades.
- Revisar detalle de propiedad.
- Revisar galería y lightbox.
- Revisar botón flotante de WhatsApp.
- Revisar feed de Instagram.
- Revisar footer.
- Revisar navegación mobile.

## Admin

- Revisar login.
- Revisar acceso owner.
- Revisar acceso editor.
- Probar cambio de contraseña.
- Probar recuperación de contraseña.
- Probar carga de propiedad.
- Probar subida de imágenes.
- Probar publicación y ocultado.
- Probar importador de Instagram.
- Probar acceso rápido para volver al panel desde la web pública.

## SEO

- Revisar `https://victor-abadie-web.vercel.app/sitemap.xml`.
- Revisar `https://victor-abadie-web.vercel.app/robots.txt`.
- Confirmar verificación en Google Search Console.
- Revisar metadata básica de home, propiedades y detalle.
- Revisar que el admin esté configurado como noindex.
