# Manual de uso del panel admin

Este manual resume las acciones principales del panel de Víctor Abadie Inmobiliaria.

## 1. Acceso al panel

URL de acceso:

https://victor-abadie-web.vercel.app/admin/login

Ingresar con el email y la contraseña asignados. El acceso está limitado a usuarios autorizados.

## 2. Cambio de contraseña

1. Entrar al panel.
2. Ir a **Mi cuenta**.
3. Escribir la nueva contraseña.
4. Guardar los cambios.

## 3. Recuperar contraseña

1. Entrar a la pantalla de login.
2. Usar la opción **Olvidé mi contraseña**.
3. Revisar el email recibido.
4. Abrir el enlace y definir una nueva contraseña.

## 4. Roles

**Owner**

- Tiene control total del panel.
- Puede gestionar propiedades y acciones críticas.

**Editor**

- Puede cargar, editar, publicar, destacar y subir imágenes de propiedades.
- No puede eliminar definitivamente ni gestionar configuración crítica.

## 5. Cargar una propiedad

1. Entrar a **Nueva propiedad**.
2. Completar operación, tipo, título, ubicación, precio, superficies y descripción.
3. Seleccionar imágenes.
4. Revisar los datos.
5. Guardar.

## 6. Imágenes

- Se recomienda usar imágenes cuadradas tipo Instagram o fotos de buena calidad.
- La primera imagen queda como imagen principal.
- En la ficha pública se puede ver el carrusel completo.
- Evitar imágenes demasiado pesadas si no es necesario.

## 7. Importar desde Instagram

1. Copiar el texto del post de Instagram.
2. Pegar el texto en **Importar Instagram**.
3. Presionar **Analizar publicación**.
4. Revisar y corregir los campos detectados.
5. Enviar los datos al formulario de propiedad.
6. Cargar las fotos manualmente.

## 8. Publicar u ocultar

- Usar el checkbox **Publicada** para mostrar u ocultar una propiedad en la web pública.
- Usar **Destacada** para darle mayor visibilidad comercial.

## 9. Ver sitio y volver al panel

Desde el panel se puede usar **Ver sitio** para revisar la web pública. Si el usuario sigue logueado y está autorizado, verá un acceso rápido en la parte inferior izquierda de la web pública para volver al panel.

## 10. Recomendaciones

- Revisar ortografía antes de publicar.
- Usar títulos claros y comerciales.
- Mantener precio y ubicación actualizados.
- Cargar varias imágenes cuando sea posible.
- Revisar cómo queda la ficha pública después de guardar.
